nubia Z17s Root 操作手册

NX595J

骁龙 835 (MSM8998) · Android 7.1.1 / nubia UI 5.1 · 2017 年 10 月上市

结论：可以 root，难度中等。这台机器有一条努比亚自己留在 fastboot 里的隐藏解锁命令，不需要向官方申请解锁码，也不需要账号等级或等待期。主要的不确定性有两个：一是 TWRP 的版本适配，二是解锁对指纹类功能的潜在影响。

!动手前必读的风险

这几条没有例外，请逐条确认自己能接受

1. 解锁 Bootloader 会清空手机里的全部数据。照片、聊天记录、账号、应用数据全部消失，且不可恢复。动手前先把重要文件导出到电脑。

2. 指纹支付、部分银行 App 可能失效。解锁会让设备无法通过完整性校验，依赖这一机制的功能会拒绝工作。努比亚机型走的是官方自带的解锁命令，指纹硬件本身通常不受损，但指纹支付和金融类 App 的可用性需要你做好心理准备。

3. 操作失误可能导致无法开机。高通平台可以用 9008 (EDL) 底层模式救回来，但前提是你提前下载好了官方固件包。没有救砖包之前，不要开始刷机。

另外两条影响较小的：官方保修失效（这台机器早已过保）、系统 OTA 升级功能失效。

0准备清单

动手前把这些都备齐，中途缺东西是最容易出事的

硬件

软件与文件

关于 TWRP 版本。社区维护的 Z17s TWRP 有两个版本：3.7.0_9 和 3.7.0_13-FBE。后者的说明写着「Decrypt automatically on android 11/12/13 devices」，是给刷了新系统的人用的。你跑的是原厂 7.1.1，先试 3.7.0_9；如果 TWRP 启动异常或触摸失灵，再换 3.7.0_13-FBE 试。

1电脑环境

大约 5 分钟

  1. 下载 platform-tools 压缩包，解压到一个纯英文、无空格的路径，例如 D:\adb。路径带中文会导致命令找不到文件。
  2. 安装 nubia USB 驱动。装完后把手机连上电脑，打开「设备管理器」确认没有带黄色感叹号的未知设备。
  3. 在 D:\adb 文件夹空白处按住 Shift 右键，选择「在此处打开 PowerShell 窗口」，验证工具可用：
adb version
fastboot --version

2手机端设置

大约 3 分钟

  1. 设置 → 关于手机 → 连续点击「版本号」7 次，直到提示「您已处于开发者模式」。
  2. 返回 设置 → 开发者选项，打开 USB 调试 和 OEM 解锁 两个开关。
  3. 手机连上电脑，在命令行执行下面的命令。手机上会弹出「是否允许 USB 调试」，勾选「一律允许」后确定。
adb devices

列表里出现一串序列号加 device 字样就说明连接正常。

如果找不到「OEM 解锁」这个开关。两种可能：一是 nubia UI 需要先打开「USB 调试」并保持联网，该开关才会出现，重新进一次开发者选项看看；二是固件版本太旧没有暴露这个选项，那就需要先把系统升级到官方 Android 8.1 版本再继续。升级会清数据，所以这一步要在备份之后、解锁之前决定。

3解锁 Bootloader

整个流程最关键的一步 · 执行后数据会被清空

努比亚骁龙机型有一个非标准的 fastboot 命令，型号必须大写并加上 NUBIA_ 前缀。你的机器对应的是：

fastboot oem nubia_unlock NUBIA_NX595J

完整操作顺序：

adb reboot bootloader
fastboot devices
fastboot oem nubia_unlock NUBIA_NX595J

解锁成功时你会看到这样的回显，其中 set state to 1 ok 就是解锁标志：

(bootloader) START update nubia fastboot unlock flag!!!
(bootloader) set state to 1 ok!!!
OKAY [  0.053s]
Finished. Total time: 0.054s

命令无反应或报错怎么办。社区实测经验：回到开发者选项，把「OEM 解锁」开关反复关闭再打开几次，然后重新执行上面第三条命令。这是努比亚的一个已知怪癖，开关状态需要「触发」几次才会真正写入标志位。

如果反复尝试仍然无效，可以依次试这两条备用命令：

fastboot flashing unlock
fastboot oem unlock

解锁成功后手机会自动重启并清空数据，首次开机会特别慢（5 到 8 分钟），停在 logos 上是正常的。开机后屏幕可能出现解锁状态警告，属正常现象。如果超过 15 分钟还没进系统，按住电源键 10 秒强制重启，通常第二次就能进。

4刷入 TWRP

把 recovery 换成第三方恢复环境

手机处于 fastboot 模式（屏幕上显示兔子图标）时执行，把文件名换成你实际下载的那个：

fastboot flash recovery twrp_recovery_3.7.0_9_for_nx595j-new-partitions-20221116.img

回显里出现 OKAY 表示写入成功，出现 FAILED 则通常是上一步没解锁成功。

这一步有个必踩的坑：刷完绝对不能直接重启进系统。努比亚等机型的原厂系统在正常启动时会检测 recovery 分区，发现被改动就自动刷回原厂 recovery，你前面白干。刷完必须立刻进 recovery。

进 recovery 的正确方式 —— fastboot 界面自带一个可用音量键操作的菜单：

Reboot system now              <- 别选这个，会进系统、recovery 被覆盖
Reboot to recovery mode        <- 选这一项
Reboot to emrg recovery mode
Boot to edl
Power off

Press volume key to select above item, and press power key to confirm
  • 按音量键把光标移到 Reboot to recovery mode，再按电源键确认
  • 备用方式：关机后按住「音量上 + 电源键」

为什么强调用菜单而不是命令。这台设备的 bootloader 把「重启到 recovery」的相关命令全部裁掉了：fastboot oem reboot-recovery 和 fastboot boot 都返回 unknown command；最坑的是 fastboot reboot recovery 会返回 OKAY 却实际进了系统（假成功，recovery 直接被覆盖）。只有菜单这一条路是通的。

看到 TWRP 的界面就说明成功了。

5刷入 Magisk

这一步之后手机就有 root 了

  1. 手机关机状态下按住「音量上 + 电源」进入 TWRP。
  2. 把 Magisk 的包推到手机的 内存分区（不是 /sdcard）：
adb push Magisk-v26.4.zip /tmp/

为什么推到 /tmp 而不是 /sdcard。这台机器 data 分区是加密的，TWRP 环境下读不到 /sdcard 的内容（列出来全是乱码文件名）。/tmp 是 TWRP 的内存文件系统，一定可写，用它最省事。

  1. 在 TWRP 里执行安装命令：
adb shell "twrp install /tmp/Magisk-v26.4.zip"

看到 Patching ramdisk → Flashing new boot image → Done 就是成功了。也可以直接在 TWRP 界面点 Install 手动选包。

  1. 重启进系统：
adb shell "twrp reboot"

如果 TWRP 提示输入密码或读不到 /sdcard。说明 data 分区还处于加密状态。选择 Cancel 跳过密码，然后 Wipe → Format Data → 输入 yes 确认。解锁时数据已经清空了，这里没有额外损失。

如果格式化后仍然传不进文件，改用 TWRP 的 Advanced → ADB Sideload，然后在电脑上执行 adb sideload Magisk-v26.4.zip。

6验证 root 是否生效

几条命令确认结果

先装 Magisk 管理 App：

adb install Magisk-v26.4.apk

装好后打开 Magisk App，首页会显示已安装的版本号（如 26.4）—— 这是最直观的确认。

再用命令验证 root 权限：

adb shell su -c id

输出里出现 uid=0(root) 就成功了。

如果 su 命令卡住不动，那是正常的，不是故障。它在等 Magisk App 弹出授权对话框 —— 在手机上点「允许」即可。想避免命令卡死，可以加超时：adb shell "timeout 5 su -c id"。

不依赖授权也能确认 root 装好了：

adb shell "which su"                   # 应输出 /sbin/su
adb shell "ls /sbin"                   # 应看到 magisk magisk64 su resetprop 等
adb shell "pm list packages magisk"    # 应输出 com.topjohnwu.magisk

!万一变砖了

按严重程度分两级处理

还能进 fastboot 或 recovery（软砖）

这是最好处理的情况。用电脑端的努比亚官方助手识别设备后走线刷恢复，识别不到就先重装驱动。也可以直接重新刷入官方 recovery 和 boot 镜像。

完全黑屏、任何按键都没反应（硬砖）

走高通 9008 底层模式，这条路几乎总能救回来：

  1. 手机完全关机，按住「音量上键」不放，然后插上数据线连电脑。
  2. 打开设备管理器，出现 Qualcomm HS-USB QDLoader 9008 端口即成功进入。如果该端口带黄色感叹号，手动更新驱动指向高通驱动目录。
  3. 用工唯 QFIL 或努比亚线刷工具，加载官方固件包里的 prog_firehose_ddr.elf 及各分区镜像，开始刷写。

固件包必须匹配 NX595J。努比亚的型号命名很混乱，Z17、Z17 mini、Z17s 的固件包互不兼容，刷错轻则无限重启，重则彻底变黑砖。下载时确认标题里明确写着 NX595J 或 Z17s，而不是「努比亚通用」。
